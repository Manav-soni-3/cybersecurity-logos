## 🚀 How to use

Every file is named `<Tool> Official Logo (<Version>).<ext>`. Click a version name in the tables below to open that file.

| Version | Use it on |
|---|---|
| **Logo** | The main full-colour logo (symbol + name) |
| **Icon** | Small spaces: symbol only, no name |
| **White** | Dark backgrounds |
| **Black** | Light backgrounds |
| **Vertical** / **Horizontal** | Stacked or side-by-side layouts |

**Prefer SVG** when available: it scales to any size without losing quality.

> [!TIP]
> White logos are invisible on GitHub's light theme. Switch to dark mode to preview them.

> [!NOTE]
> Files named `Text Logo` (for example Sysmon) are the tool's name set in its official font, because the tool has no logo file of its own.

> [!IMPORTANT]
> All logos are trademarks of their respective owners and are collected here for reference and identification only.
